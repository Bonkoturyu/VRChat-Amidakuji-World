# ADR-0009: 観戦システムを「追いかけ式」に変更(観戦デッキ・スクリーン廃止)

- **Status**: Accepted
- **Date**: 2026-05-15
- **Supersedes**: [ADR-0004](./0004-rendertexture-spectator-screen.md)

## Context

当初設計(ADR-0004)では「物理観戦デッキ(ガラス床バルコニー) + RenderTexture俯瞰スクリーン」を採用していた。

その後、v1.0 でAndroid対応を含める方針(ADR-0010)に伴い、モバイルでは以下の課題が顕在化:

- **ガラス床(透明度)**: モバイルGPUのフィルレート上、強く非推奨
- **RenderTexture**: モバイルで +1パスが重い、解像度を落とすか削除が必要
- **PC・モバイル両方で別UXを実装する負担**: 同期バグ・テスト負荷の倍化

加えて、ユーザー体験上の再検討で「観戦者がもっと能動的に動ける方が楽しい」という方向性が出た。

## Decision

**観戦デッキとRenderTextureスクリーンを廃止し、「追いかけ式」観戦に統一する。**

### 新しい観戦体験

- 非参加者(エントリーしなかったプレイヤー)は、あみだくじ構造そのものを歩いて走り回れる
- カートが走行中、走る速度よりカートはやや速い(2.0 m/s)が、ショートカットすれば追いつける
- 観戦者はカートの直近をついていって、各カートの分岐の瞬間を間近で見られる
- ただし **ゴール手前のバリア** より先には進めない(物理メッシュコライダーで遮断)
- 賞品エリアには参加者のみ(カートがバリアの隙間を通り抜けてテレポート)

### 物理構造の変更

- あみだくじ本体の床(縦線・横線の床部分)は **歩行可能なメッシュ + コライダー**
- カートと歩行者は **衝突しない**(Layerまたはコライダー設定でレイヤー分離)
- ゴール手前 1m 程度の位置に、**カートが通る隙間だけ空いた壁** を設置
  - 壁の幅: 縦線 4 本に対応した4列、それぞれカート幅 + α の隙間
  - 歩行者は隙間を通り抜けられないサイズに設定(壁の厚みで物理的に塞ぐ)
- ガラス床は廃止(透明度自体を v1.0 の世界から除去)

### PC / Android で挙動共通

PCもAndroidも完全同一の観戦体験。プラットフォーム分岐は一切無し。

## Consequences

### Positive

- **モバイル対応がほぼ自動的に満たされる**: 透明・RenderTexture という最大の負荷源が消える
- **UXが能動的・体感的になる**: 「見る」より「追いかける」体験は VR/Quest 共に没入感が高い
- **実装工数削減**: Phase 5(RenderTexture)と Phase 6(観戦デッキ)が消え、合計2日分の工数が浮く
- **テスト負荷半減**: PCとAndroidで挙動が同じため、片方で動けば他方も動く可能性が高い

### Negative

- エントリーエリアからの「全体俯瞰」が失われる(カートを上から見たい派には残念)
- 走るのが苦手なプレイヤーは観戦が物理的に大変
- ゴール手前バリアの設計に手間がかかる(カートだけ通って人は通さない隙間設計)

### v1.1 以降の拡張余地

- 「観戦モード」として上空に飛んでフリーカメラできるUDONギミック追加
- スピード調整: 観戦者向け加速ゾーン(誰でも速く走れる場所)
- リプレイ機能との連動(俯瞰カメラがリプレイ時のみ有効化)
