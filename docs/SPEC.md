# 仕様書 (v1.0 ロック)

最終更新: 2026-05-15  
Status: **Locked** (v1.0開発期間中はこの仕様で進行)

## 1. コンセプト

巨大あみだくじを「自動巡回する乗り物 (カート)」に乗って体験するVRChatワールド。

- 4人が同時に参加し、それぞれのスタート位置に対応したカートに乗る
- インスタンスオーナーがスタートボタンを押すと、ランダム生成されたあみだくじに従って各カートが自動巡回
- カートがゴールに到達すると、対応する賞品エリアにプレイヤーがテレポートされる
- 非参加者は観戦デッキおよび大型スクリーンで全カートの動きを観戦できる

## 2. プレイヤーロール

| ロール | 行動 | 制約 |
|---|---|---|
| 参加者 | カートに座って走行を体験 | 走行中は降車不可(VRトリガー退出時はリタイア扱い)、Idle中のみ着座可 |
| 観戦者 | 観戦デッキ・スクリーンで観戦 | 自由移動可 |
| インスタンスオーナー | 上記に加え、スタートボタン操作権 | `Networking.IsMaster` が true なクライアント |

## 3. ワールド構成

### 3.1 エリア構成

- **スポーンエリア**: ワールド入場時の初期位置。ルール説明パネル設置
- **エントリーエリア**: カートの待機位置。座席はここに4つ並ぶ。スタートボタンと観戦スクリーンも設置
- **あみだくじ本体**: 縦に長い構造。スタートから下に向かってカートが進む
- **観戦デッキ**: あみだくじを横〜上方から見られるバルコニー(ガラス床推奨)
- **賞品エリア**: ゴール後にプレイヤーがテレポートされる先(4ゾーン)

### 3.2 配置の方向性

あみだくじ本体は**縦置き**(高さ方向に長い)。カートは上から下に向かって落下に近い感覚で進む。観戦デッキはあみだくじの中段から上方にかけて配置。

物理的な寸法・座標は [docs/scene-structure.md §7](./scene-structure.md) を参照。

## 4. あみだくじ生成ルール

### 4.1 構造

- 縦線本数: **4** (v1.0固定。内部実装は可変対応 → [ADR-0008](./adr/0008-4lane-scope-scalable-design.md))
- 縦線間隔: 4.0 m
- 縦線長さ: 60.0 m (=Y方向)
- 横セグメント数: 12(縦線長さを12分割、各セグメント境界で横線生成判定)
- 横線生成確率: 各セグメント境界で、各隣接縦線ペアに対し 50% で生成
- 連続横線禁止: 同じ高さで隣接する横線は同時生成しない(あみだくじの数学的制約)

### 4.2 生成タイミング

- インスタンスオーナーがスタートボタンを押した瞬間に seed が決定
- seed は `UdonSynced` で全クライアントに配布
- 各クライアントが seed から同じアルゴリズムで横線配置を再構築

詳細は [ADR-0002](./adr/0002-deterministic-rng-seed-sync.md)。

### 4.3 視覚化

- 横線はシーンに「全パターン分」事前配置、enable/disable で表示制御
- 上記制約により最大横線数は固定値(縦線4本×セグメント12 = 隣接ペア3×12 = 最大36本)

## 5. カート挙動

### 5.1 構造

- カートは GameObject。`VRC_Station` を子に持つ
- カートTransformをUdonで動かすと、座っているプレイヤーも追従
- Station 設定の詳細・走行中退出時の挙動は [ADR-0007](./adr/0007-vrcstation-transform-cart.md)

### 5.2 経路計算

スタート時に seed から各カートの通過Waypoint配列をローカルで計算する。アルゴリズム詳細は [ADR-0003](./adr/0003-precomputed-waypoint-lerp.md)。

### 5.3 移動補間

- 各セグメント間を一定速度で Lerp 移動
- 速度: **2.0 m/s** (調整可)
- 横線通過時も同速度で水平移動
- 経過時間は `Networking.CalculateServerDeltaTime(now, raceStartTime)` で算出

## 6. ゲームフロー (ステートマシン)

```
[Idle]
  ├─ 着座イベント → 参加者登録 (最大4人、Idle中のみ可)
  └─ Masterがスタート押下 (参加者1人以上) → [Countdown]

[Countdown]  (3秒)
  └─ 3秒経過 → seed生成・配布、raceStartTime記録 → [Running]

[Running]
  └─ 全カートゴール到達 → 賞品エリアテレポート → [ResultDisplay]
  └─ VRトリガー退出はリタイア扱い、走行は継続

[ResultDisplay]
  └─ 10秒経過 → [Idle]
```

v1.0では走行キャンセル機能は実装しない。状態遷移の実装パターンは [architecture.md](./architecture.md) 参照。

## 7. UI仕様

### 7.1 着座(エントリー)

- 4つの座席に `VRC_Interact` で着座
- Idle時のみ反応、Countdown/Running/ResultDisplay中は無反応
- 着座すると `participantPlayerIds[laneIndex]` に自分のPlayerIDが書き込まれる

### 7.2 スタートボタン

- エントリーエリアに大きく配置
- `Networking.IsMaster` 時のみ押下可、それ以外はビジュアルでグレーアウト
- 参加者0人時は押下不可
- gameState が Idle 以外のときも無効

詳細な権限モデルは [ADR-0006](./adr/0006-instance-owner-start.md)。

### 7.3 結果表示

- ゴール直前または直後にカート位置の上に「Goal N」表示
- ResultDisplayステート中、スクリーンに各プレイヤーの結果(座席番号 → ゴール番号)を表示

## 8. 観戦システム

### 8.1 物理観戦デッキ

- あみだくじ構造の中段〜上方に配置
- 床はガラス(Transparent Material)で頭上俯瞰可能
- 観戦者は自由移動

### 8.2 RenderTextureスクリーン

- v1.0は俯瞰カメラ1台のみ
- スクリーン1枚(エントリーエリアに大きく配置)
- 解像度: 1280×720
- カメラ: あみだくじ本体の真上、Orthographic projection、Culling Maskで観戦者・UIを除外、Clear Flags = Solid Color

実装方針は [ADR-0004](./adr/0004-rendertexture-spectator-screen.md)。

## 9. 同期モデル

### 9.1 Synced変数 (UdonSynced)

| 変数 | 型 | 用途 |
|---|---|---|
| `seed` | int | あみだくじ生成シード |
| `gameState` | int (enum: 0=Idle,1=Countdown,2=Running,3=ResultDisplay) | ステート |
| `raceStartTime` | double | サーバー時刻ベースのレース開始時刻 |
| `participantPlayerIds` | int[4] | 各座席に座っているプレイヤーID (-1=空) |

### 9.2 同期しない情報

- 各カートの現在位置(seed + 経過時間からローカル算出)
- 横線の状態(seedからローカル算出)
- 各クライアントのUI状態

同期最小化の判断根拠は [ADR-0005](./adr/0005-minimal-sync-variables.md)、Late Joinerシーケンスは [architecture.md](./architecture.md) を参照。

## 10. パフォーマンス目標

- VR HMD でスポーン地点 45 FPS 以上
- PC Good ランク
- 詳細なバジェット値は [CLAUDE.md パフォーマンスバジェット](../CLAUDE.md#パフォーマンスバジェット-pc-good-ランク目標) を参照

## 11. 非対応事項 (v1.0)

- Quest版対応 (PC専用)
- 20人スケール (v1.1で対応)
- ランダムイベント(ボーナス・トラップ等)
- BGM(簡易効果音のみ実装。完全なBGMはv1.1)
- カスタム賞品(賞品エリアは固定)
- 走行キャンセル機能
- スクリーンのカメラアングル切り替え
- 多言語対応

## 12. v1.0 完了の定義

以下を全て満たした状態を「v1.0完了」とする:

1. 4人参加でランダムあみだくじが生成され、全カートが正しく経路を辿りゴールする
2. ゴール後に各参加者が対応する賞品エリアへテレポートされる
3. 観戦者がスクリーン経由・観戦デッキ経由でレースを観戦できる
4. Late Joiner が走行中・Idle中・ResultDisplay中それぞれで途中参加してもクラッシュ・状態不整合が起きない
5. PC Good ランクを満たし、VR HMD でスポーン地点 45 FPS 以上を確保している
6. Community Labs 公開ボタンを押下可能な状態(Trust Rank・ワールド情報・サムネイル等が揃っている)

実際のステータストラッキングは [BACKLOG.md](../BACKLOG.md) のチェックリストで行う。
