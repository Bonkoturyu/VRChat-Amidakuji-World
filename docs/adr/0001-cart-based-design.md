# ADR-0001: あみだくじ体験方式に「カート式 (B案)」を採用

- **Status**: Accepted
- **Date**: 2026-05-15

## Context

巨大あみだくじワールドの体験設計として以下4案を検討:

- **A. 歩き型**: プレイヤーが自分で歩いてあみだくじを辿る。交差点でTeleport/壁誘導
- **B. 乗り物型**: VRC_Stationに座って自動で巡回
- **C. 落下型**: 物理ボール的に上から落ちる
- **D. 観賞型**: 玉が小さくプレイヤーは観るだけ

## Decision

**B案 (乗り物型)** を採用する。

理由:

1. **同期難易度**: A案はプレイヤー位置・誘導イベントの同期が複雑。B案は「カートTransformを動かすだけ」で同期がシンプル
2. **公平性**: A案は歩行速度がプレイヤーに依存し体験差が出る。B案は全員同じ
3. **観戦との相性**: B案は走行速度が揃うため、観戦スクリーンで全カートを一画面に収めやすい
4. **VR/Desktop両対応**: B案はDesktopプレイヤーでも普通に体験できる
5. **VRC_Stationの安定性**: 既存ワールドで広く使われているパターンで実装事例が豊富

## Consequences

### Positive

- 同期負荷低い
- 制作工数低い
- 観戦UXが綺麗にハマる

### Negative

- インタラクティブ性は控えめ(乗ってるだけ)
- 演出の盛り上がりはカート挙動と賞品エリアに依存する

### v1.1以降での再考余地

将来的に「カート式」と「歩き式」の二択モードを提供する案はある (BACKLOG)。
